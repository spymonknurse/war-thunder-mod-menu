## 🧩 About

**War Thunder Mod Menu** is a curated list of War Thunder open-source tools:

- **Quality-of-Life Helpers** — vehicle catalog, loadout manager, overlay notes

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Vehicle Info — review stats and modules from any hangar view
- Show Telemetry — visualize speed, altitude, and bearing data
- Battle Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### Wallhack
- Vehicle Catalog — browse aircraft, tanks, and ships with colors and decals
- Custom Skin Notes — organize player cosmetics
- Marker Visibility — improved squad marker clarity

### Aimbot
- Test Flight Notes — segment study on any vehicle layout
- Camera Control — manually adjust free-camera angles
- Input Buffer Notes — chain complex maneuvers in test range
